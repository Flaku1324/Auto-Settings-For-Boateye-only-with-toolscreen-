Use only on Windows with Toolscreen and Ninjabrainbot already installed. 
Project still in developement, may not work in some cases.

How to use:

-Make sure Toolscreen and Ninjabrainbot have been installed and opened at least once.

-Close Minecraft and Ninjabrainbot

-Run auto_boateye_settings.exe

-Select the directory of your Minecraft instance (it can either be the instance folder or the "minecraft" folder inside the instance)

-Click "Select Folder"

-Click "ok" and reopen Minecraft and Ninjabrainbot.
